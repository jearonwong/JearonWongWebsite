# Agent Entry Point

This repository uses `AGENTS.md` as the canonical agent contract.

Read `AGENTS.md` first.

For strategic judgment, architecture/product/protocol boundary work, Codex prompt generation, Codex result review, correction, high-risk release/projection/migration/copyright work, or dynamic governance routing, also read:

- `.agents/skills/dialogue-execution-harness-governance/SKILL.md`

For site identity, homepage positioning, core definitions, navigation semantics, metadata, `llms.txt`, or cross-page UI/UX consistency work, also read:

- `.agents/skills/site-semantic-brand-governance/SKILL.md`
- `src/data/siteGovernance.ts`

For essay, article, white paper, research artifact, OG/social asset, RSS/sitemap, or publication audit work, also read:

- `.agents/skills/site-publication-surface-governance/SKILL.md`
- `.agents/skills/article-publication-governance/SKILL.md` when essays/articles are involved
- `docs/governance/ARTICLE_PUBLICATION_GOVERNANCE_BASELINE.md`
