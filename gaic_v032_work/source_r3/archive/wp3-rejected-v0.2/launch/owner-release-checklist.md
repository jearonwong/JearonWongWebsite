# AIIRWP Owner Release Checklist

Use this checklist before any owner-executed distribution. Default state is `pending owner execution`.

## Review Checklist

- [ ] Review production route.
- [ ] Review PDF cover.
- [ ] Review PDF TOC.
- [ ] Review Chapter 4 responsibility bridge figure.
- [ ] Review Chapter 5 market table.
- [ ] Review Appendix A source notes.
- [ ] Confirm title: Agentic AI Insurability & Risk Transfer White Paper 2026.
- [ ] Confirm subtitle: A Lifecycle Evidence Guide for Underwriting, Claims, and Enterprise Risk Transfer.
- [ ] Confirm no-DOCX public distribution.
- [ ] Confirm boundary language.
- [ ] Confirm LinkedIn draft.
- [ ] Confirm newsletter draft.
- [ ] Confirm X draft.
- [ ] Confirm target distribution groups.
- [ ] Confirm whether to publish today or hold.
- [ ] Confirm whether post-release evidence capture should begin after owner execution.
- [ ] Confirm Final Seal is not authorized unless separately approved.

## Decision Options

| Decision option | Status | Notes |
| --- | --- | --- |
| Approve release execution | not selected | Owner must explicitly approve before distribution. |
| Hold release | not selected | Use if timing, strategy, or readiness requires delay. |
| Require wording edits | not selected | Use if launch copy needs revision. |
| Require visual edits | not selected | Use if route/PDF presentation needs revision. |
| Require distribution strategy changes | not selected | Use if channel sequencing or audiences need revision. |
| Pending owner execution | selected | Default R17 state. |
