# Distribution Boundary Guardrails

## Allowed Language

- public research candidate
- source-grounded analysis
- technical governance research
- auditability framework
- lifecycle evidence model
- proposed readiness model
- proposed evidence model
- non-certifying
- not legal advice
- not an audit standard
- not an assurance opinion
- not a procurement ranking
- production route live
- public artifacts live
- semantic mapping live

## Forbidden Language

- certified
- regulator-approved
- Big Four endorsed
- audit-body endorsed
- legally compliant
- proves compliance
- audit standard
- assurance-ready as an assurance opinion
- proven by regulators
- industry standard
- required protocol
- MPLP required
- SEO/GEO achieved
- indexed by AI engines
- answer-engine recognized
- adopted by vendors
- vendor ranking
- procurement recommendation

## Safe Replacements

| Risky Phrase | Safe Replacement |
| --- | --- |
| "certified framework" | "non-certifying research framework" |
| "regulator-approved" | "source-grounded against public governance and regulatory context" |
| "Big Four endorsed" | "written for audit, assurance, and governance readers without claiming endorsement" |
| "legally compliant" | "designed to support governance discussion, not legal compliance proof" |
| "audit standard" | "auditability framework" |
| "assurance-ready opinion" | "readiness model for discussing evidence architecture" |
| "industry standard" | "proposed model" |
| "required protocol" | "optional protocol path" |
| "SEO/GEO achieved" | "technical visibility wiring prepared and monitored" |
| "indexed by AI engines" | "answer-engine/search monitoring pending evidence" |
| "adopted by vendors" | "available as public research" |
| "vendor ranking" | "non-ranking governance analysis" |
| "procurement recommendation" | "not procurement guidance" |

## Evidence Rule

Only claim what has been executed and recorded:

- published post URL
- newsletter URL
- group post URL
- screenshot/export path
- answer-engine result screenshot with visible source
- search result screenshot or export
- external mention/backlink URL
- owner note with timestamp and context
