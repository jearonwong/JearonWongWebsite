# Whitepaper Canonical Registry

This directory is the canonical registry and workspace root for the Agentic Lifecycle Governance Industry Series.

Future Codex tasks must inspect `registry/whitepaper-series-registry.yaml` and `registry/current-status.md` before creating, rewriting, staging, validating, or publishing any whitepaper artifact.

## Purpose

- Separate current source truth from historical wave directories.
- Prevent new WP3 work from being buried in `wp3_rXX_*` folders.
- Preserve rejected candidate history without treating it as active source.
- Establish AIIRWP v1.0 as the only active WP3 rewrite workspace.

## Current Rule

WP3 / AIIRWP v0.2 is withdrawn and rejected. WP3 v1.0 rewrite work belongs under `whitepapers/aiirwp/v1/`.
