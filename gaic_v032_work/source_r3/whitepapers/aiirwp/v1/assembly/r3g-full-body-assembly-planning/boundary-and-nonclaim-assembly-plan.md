# Boundary and Non-Claim Assembly Plan

## Purpose

This plan defines the final boundary architecture for R3H assembly. It protects the argument from becoming advice, standard, score, certification, coverage opinion, or public release claim.

## Boundary Layers

R3H should use four layers:

1. Global non-claim note in Front Matter.
2. Chapter-level boundary notes for high-risk chapters.
3. Chapter 27 final non-claim boundary register.
4. Appendix boundary language if appendices are later authorized.

## Global Non-Claim Note

The global note should state that the paper is an analytical whitepaper about insurability reasoning and risk-transfer evidence. It should not provide legal advice, insurance advice, underwriting guidance, coverage opinion, actuarial pricing guidance, premium recommendation, claim approval guidance, legal liability determination, certification, proof of insurability, insurer endorsement, regulator-approved method, score, standard, readiness certification, procurement recommendation, vendor ranking, public release, or final/sealed status.

## Chapter-Level Boundary Notes

R3H should retain chapter-level boundary notes where reader misuse risk is high:

- market signal chapters;
- coverage-line and coverage-boundary chapters;
- underwriting-facing evidence chapters;
- premium/exposure variable chapter;
- claim reconstruction and dispute chapters;
- final model chapters.

Lower-risk chapters may use shorter boundary language if Chapter 27 remains strong.

## Final Non-Claim Boundary Register

Chapter 27 should remain the central final boundary register. Do not weaken it during repetition compression.

## Appendix Boundary Language

If appendices are later scoped, each appendix should include a short boundary note. Appendix templates or registers must not be framed as required standards, insurer checklists, claim demands, procurement requirements, certifications, or regulator-approved methods.

## Forbidden Positive Claims

R3H and later waves must not make positive claims of:

- legal advice;
- insurance advice;
- underwriting guidance;
- coverage opinion;
- actuarial pricing guidance;
- premium recommendation;
- claim approval guidance;
- legal liability determination;
- certification;
- proof of insurability;
- insurer endorsement;
- regulator-approved method;
- procurement recommendation;
- vendor ranking;
- score;
- standard;
- readiness certification;
- public release;
- final/sealed status;
- public candidate status;
- insurer acceptance;
- coverage-ready status;
- underwriting-ready status;
- claim-ready status;
- external adoption;
- indexing, SEO-GEO, or answer-engine recognition outcome;
- WP4 implementation.

## Safer-Language Rules

| Risky wording | Safer wording |
|---|---|
| Insurable / uninsurable as a final status | More reviewable / harder to review as analytical risk-readiness language |
| Insurer will accept | May support a more structured risk discussion; insurer decision remains external |
| Underwriting checklist | Optional reviewer evidence request structure |
| Pricing variable | Non-pricing exposure variable for discussion |
| Claim-ready evidence | Reconstruction-supporting evidence |
| Coverage boundary conclusion | Coverage-boundary question |
| Legal liability | Responsibility evidence / legal conclusions remain external |
| Certification / standard | Authored analytical construct |
| Score / grade / rating | Non-scoring reasoning state |
| Required by insurers | Potentially useful for reviewer discussion, not an insurer requirement |
| Proof of insurability | Evidence that may improve reviewability |

## Public Status Boundary

R3H should preserve public status:

- WP3 remains withdrawn / v1.0 rewrite in progress.
- Current public artifact remains none.
- Current public PDF remains none.
- Public route remains noindex under-rewrite status page.
- R3H internal assembly does not authorize artifact generation or public restoration.
