# Appendices Outline

## Appendix A: Public Insurance Market Signal Register

| Field | Outline |
|---|---|
| Purpose | Convert the R1 insurance market signal matrix into a citable appendix table. |
| Reader use | Quickly compare cover, exclusion, sublimit, silent exposure, cyber, professional liability, D&O/governance, claim reconstruction, aggregation, model-performance warranty, and agentic lifecycle gap. |
| Source basis | R1 `insurance-market-signal-matrix.md`; verified inventory. |
| Table/checklist plan | Full signal matrix with source strength and what each signal does/does not prove. |
| Boundary risk | Overstating market-wide proof or insurer acceptance. |
| R3 drafting instruction | Keep table source-strength column; do not remove "what it does not prove." |
