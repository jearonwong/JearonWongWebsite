# Integration Source and Citation Plan

## Purpose

This plan defines source handling for a future internal integrated draft. R3O does not integrate the draft or perform source strengthening.

## Source Reference Continuity

R3P must preserve source refs `[1]` through `[62]` from the R3J revised body.

R3P must not:

- renumber source refs;
- drop existing source caveats;
- use rejected v0.2 as current source truth;
- introduce new external factual claims without separate source support;
- convert market/context sources into proof;
- convert cyber/cloud/reinsurance analogies into direct AI insurance proof unless the source directly supports the AI claim;
- convert WP1/WP2 into insurance facts.

## Appendix F Placement

Appendix F should remain in the integrated draft as the source and claim-boundary appendix. It should summarize source-use discipline without replacing inline source markers.

Recommended handling:

- Keep inline source refs in the body.
- Keep Appendix F as source-group and caveat summary.
- Do not create a new source bibliography in R3P unless separately scoped.
- Do not use Appendix F to expand claims beyond the R3J/R3M source base.

## Source Caveats To Preserve

R3P must preserve caveats that:

- market sources are context, not policy interpretation;
- product examples do not prove market-wide acceptance;
- broker and industry sources do not determine coverage;
- cyber/cloud/reinsurance sources are analogies unless directly tied to AI;
- governance and incident-response sources support evidence/reconstruction concepts, not claim approval;
- WP1/WP2 remain analytical foundations only;
- author synthesis labels remain for AIO/AIRM-style constructs.

## Rejected v0.2 Rule

Rejected v0.2 may be mentioned only as historical boundary context through governance files. It must not be used as source truth, citation source, or body/appendix drafting base.

## Source Gaps

The following remain strengthening opportunities, not blockers before R3P integration drafting:

- exact exclusion/sublimit primary wording;
- insurer claim documentation;
- AI underwriting questionnaires.

If R3P attempts to add insurer-specific, claim-handling, policy-wording, questionnaire, endorsement, sublimit, exclusion, regulatory, broker, reinsurer, or vendor-specific factual claims beyond the existing source base, that work should be deferred to source strengthening.

## R3P Recommendation

Preserve refs `[1]` through `[62]`, preserve existing caveats, keep Appendix F as source-boundary summary, and avoid adding new external factual claims.
