# Body Appendix Cross-Reference Plan

## Purpose

This plan defines whether and how R3P may add minimal body-to-appendix references in a future internal integration draft. R3O does not add those references.

## Safe Wording Templates

Use short internal navigation language only:

- "See Appendix A for a reference version of this analytical model."
- "See Appendix B for a non-scoring reference structure."
- "See Appendix C for an optional analytical evidence-request structure."
- "See Appendix D for a reconstruction and evidence-gap reference structure."
- "See Appendix E for a coverage-boundary question map."
- "See Appendix F for source-use and claim-boundary notes."
- "See Appendix G for a non-claim boundary register."
- "See Appendix H for table inventory and layout-risk notes."

## Forbidden Wording

Do not use cross-reference wording that says or implies:

- standard;
- checklist;
- certification;
- required evidence;
- insurer-accepted;
- coverage-ready;
- underwriting-ready;
- claim-ready;
- score;
- rating;
- readiness level;
- compliance path.

## References To Avoid

Avoid cross-references in:

- body paragraphs where a reference would disrupt argument flow;
- high-risk insurance/legal claims where the reference could look like authority;
- chapters where an appendix pointer would imply that an evidence structure is mandatory;
- public status or release notes.

## R3P Instruction

R3P may add only minimal safe references. Any substantive body rewrite, new source claim, appendix expansion, or public artifact work remains out of scope unless separately authorized.
