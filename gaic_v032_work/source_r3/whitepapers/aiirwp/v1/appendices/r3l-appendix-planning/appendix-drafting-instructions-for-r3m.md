# Appendix Drafting Instructions for R3M

## Expected Next Wave

R3M should draft appendices only if R3L is accepted.

## Scope for R3M

R3M should draft appendix content using the R3L appendix plan and the R3J revised internal full-body draft as the body reference.

R3M should keep appendices as reference material, not standards, checklists, certifications, insurer-adopted methods, coverage paths, or release artifacts.

## R3M Must Preserve

- R3J body remains the current body snapshot unless body edits are separately scoped.
- 28-chapter body structure.
- T-02-01 and T-04-01 through T-27-01.
- Source refs `[1]` through `[62]`.
- WP3 public status: withdrawn / v1.0 rewrite in progress.
- Public artifact: none.
- Public PDF: none.
- Public route: noindex under-rewrite status page.
- AIO/AIRM as authored analytical constructs only.
- Reasoning Model as non-scoring.
- Reviewability is not coverage.
- Auditability is not insurability.
- Governance is not claim approval.

## R3M Must Not

- revise the body unless separately scoped;
- generate artifacts;
- modify public route;
- create PDF, DOCX, HTML, manifest, checksum, public staging, public CTA, or release-package files;
- claim public candidate, final, sealed, release-ready, coverage-ready, underwriting-ready, claim-ready, certified, score, standard, insurer-accepted, insurer-adopted method, or public release status;
- perform source-strengthening research unless separately authorized;
- convert appendices into underwriting checklists, claim demands, procurement requirements, certification checklists, coverage opinions, pricing guides, claim approval packages, or insurer-adopted methods.
