# Candidate Source Preservation Scan Plan

## Purpose

Define required preservation scans for a future candidate source creation wave.

## Required Scans

| Scan | Required result |
|---|---|
| Front Matter present | PASS required. |
| Part I through Part VI present | PASS required. |
| Chapters 1-28 present | PASS required. |
| Chapter 28 prose conclusion present | PASS required. |
| Appendix A-H present | PASS required. |
| Appendix I deferred note present unless owner changes it | PASS required unless owner authorizes inclusion/change. |
| Source refs `[1]` through `[62]` present | PASS required. |
| Table IDs `T-02-01`, `T-04-01` through `T-27-01` present | PASS required. |
| No duplicate body table IDs | PASS required. |
| Rejected v0.2 not used as source truth | PASS required. |
| Public status remains withdrawn / v1.0 rewrite in progress unless separately changed | PASS required. |
| No public artifact claim | PASS required. |
| No final/sealed/release-ready claim | PASS required. |
| No public DOCX authorization | PASS required. |

## Comparison Basis

Future scans should compare any authorized candidate source against the R3P integrated internal draft and R3P reports, with R3Q/R3U QA findings used as guardrails.

## R3V Boundary

R3V defines preservation scans only. It does not create a candidate source and does not run candidate-source creation scans against a candidate file.
