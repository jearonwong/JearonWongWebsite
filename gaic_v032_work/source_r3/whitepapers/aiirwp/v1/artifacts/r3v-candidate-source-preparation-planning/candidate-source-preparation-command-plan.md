# Candidate Source Preparation Command Plan

## Purpose

Plan future command categories or manual procedure without executing them.

## Future Procedure Categories

A later authorized wave may plan or execute:

- copy or derive source from R3P integrated draft only if later authorized;
- normalize frontmatter/status block;
- run source ref scan;
- run table ID scan;
- run appendix presence scan;
- run boundary scan;
- run no-DOCX scan;
- run rejected-v0.2 regression scan;
- run public-status scan;
- run `git diff --check`;
- update governance only if later authorized.

## Stop Conditions

Future command/procedure work must stop if it would:

- create a candidate source without explicit authorization;
- mutate the R3P integrated draft in place;
- create HTML/PDF/DOCX, manifest, checksum, or public artifacts;
- change public route, CTA, staging, sitemap, robots, `llms.txt`, entity graph, or release package state;
- claim final, sealed, release-ready, public candidate, public release, insurer acceptance, coverage readiness, underwriting readiness, claim readiness, certification, score, standard, or insurer-adopted method status.

## R3V Boundary

No command is executed in R3V to create candidate source.

No candidate file is written in R3V.
