# R3W Candidate Source Planning QA Instructions

## Purpose

Prepare the next wave.

## R3W Scope

R3W should QA R3V candidate source preparation planning only.

R3W should not create publication-candidate Markdown.

R3W should not generate artifacts.

R3W should not create HTML, PDF, DOCX, manifest, or checksum.

R3W should not modify public route.

R3W should decide whether to proceed to:

- candidate source planning repair;
- source strengthening;
- candidate source creation planning;
- or blocked.

## Public Status to Preserve

R3W must preserve WP3 public status:

- withdrawn / v1.0 rewrite in progress;
- public artifact none;
- public PDF none;
- public route noindex under-rewrite;
- no public DOCX authorized.

## Boundary

R3W must not claim public candidate, final, sealed, release-ready, coverage-ready, underwriting-ready, claim-ready, certified, score, standard, insurer-accepted, insurer-adopted method, or public release status.
