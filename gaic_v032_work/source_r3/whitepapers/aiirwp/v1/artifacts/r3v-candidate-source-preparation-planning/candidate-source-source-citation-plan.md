# Candidate Source Source Citation Plan

## Purpose

Plan source/citation handling for future candidate source creation.

## Source Reference Preservation

Source refs `[1]` through `[62]` must be preserved in any future candidate source.

Future source scans should compare R3P source refs to candidate source refs and flag any missing, renumbered, silently dropped, or context-stripped references.

## Rejected v0.2 Exclusion

Rejected v0.2 must not be used as source truth, drafting base, citation source, or publication basis. It remains historical boundary context only through governance records.

## Unsupported Claims

Future candidate source creation must not add new unsupported external factual claims. Any new factual claim would require a separately scoped source-strengthening or source-validation wave.

## Caveat Preservation

Existing source caveats must be preserved, including:

- market/context sources are context, not policy interpretation;
- product examples do not prove market-wide acceptance;
- cyber/cloud/reinsurance analogies remain contextual unless directly tied to AI by source support;
- governance and incident-response sources support evidence/reconstruction concepts, not claim approval;
- WP1/WP2 remain analytical foundations only;
- author synthesis labels remain for AIO/AIRM-style constructs.

## Source Gaps

The following remain strengthening opportunities unless later judged blockers:

- exact exclusion / sublimit primary wording;
- insurer claim documentation;
- AI underwriting questionnaires.

## R3V Boundary

R3V does not perform source-strengthening research and does not create a candidate source. Candidate source creation must not silently drop citations or caveats in any later wave.
