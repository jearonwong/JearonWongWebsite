# Candidate Source Frontmatter and Status Plan

## Purpose

Plan frontmatter/status language for the future candidate source.

## Planned Fields

Future candidate source frontmatter should include:

| Field | Planned value discipline |
|---|---|
| `title` | AIIRWP white paper title. |
| `subtitle` | Series-consistent subtitle if later authorized. |
| `version` | `v1.0`. |
| `wave_id` | Future authorized candidate source preparation wave ID. |
| `source_basis` | R3P integrated internal draft path. |
| `status` | Internal publication-candidate source preparation status. |
| `public_status` | Withdrawn / v1.0 rewrite in progress unless separately changed. |
| `artifact_status` | Not a public artifact; artifact generation not authorized by this source alone. |
| `route_status` | Noindex under-rewrite unless separately changed. |
| `generated_artifacts` | None unless a later generation wave authorizes and records them. |
| `source_refs_range` | `[1]` through `[62]`. |
| `table_id_range` | `T-02-01`, `T-04-01` through `T-27-01`. |
| `appendix_status` | Appendix A-H present; Appendix I deferred unless owner changes it. |
| `rejected_v0_2_exclusion` | Rejected v0.2 excluded from source truth and citation source. |
| `non_claim_status` | Non-claim, non-certifying, non-scoring research source posture. |
| `no_docx_status` | Public DOCX unauthorized. |

## Safe Status Language

Future frontmatter/status language should include:

- `internal publication-candidate source preparation`;
- `not a public artifact`;
- `not final`;
- `not sealed`;
- `not release-ready`;
- `not public candidate unless later authorized`;
- `artifact generation not authorized by this source alone`.

## Prohibited Status Language

Future frontmatter/status language must not include public release language or imply that candidate source creation authorizes artifact generation, public route restoration, public candidate status, final/sealed status, release-ready status, public release, insurer acceptance, coverage readiness, underwriting readiness, claim readiness, certification, score, standard, or insurer-adopted method status.

## R3V Boundary

R3V plans frontmatter/status fields only. It does not write a candidate source frontmatter block into any candidate file.
