## Candidate Source Table Discipline

The candidate source should preserve table content before HTML/PDF layout treatment. It should not split, condense, convert, restyle, or remove table content solely for layout purposes unless a later authorized wave defines and QA's that change.

Appendix table labels must not conflict with body table IDs.

## Future Layout Gates

HTML/PDF layout decisions remain future gates. These include horizontal scroll, table card pattern, split tables, condensed tables, landscape-style PDF handling, or appendix summary treatment.

## R3V Boundary

R3V does not implement layout. R3V creates no HTML, PDF, CSS, DOCX, manifest, checksum, or visual artifact. R3V plans candidate source table preservation only.
