# Generation Boundary and Non-Claim Plan

## Purpose

Define non-claim controls for a future generation wave.

## Future Status Language Controls

| Surface | Required status language planning |
|---|---|
| Candidate source | Internal candidate source only if later authorized; not final, sealed, release-ready, or public release. |
| HTML banner/status | Internal candidate status and non-claim boundary if later generated. |
| PDF cover/status | Internal candidate status, non-certifying research status, and no public release claim if later generated. |
| Manifest/status | Integrity/status metadata only; not release certification or public authorization. |

## Forbidden Positive Claims

Future generation work must not positively claim:

- legal advice;
- insurance advice;
- underwriting guidance;
- coverage opinion;
- actuarial pricing guidance;
- premium recommendation;
- claim approval guidance;
- legal liability determination;
- certification;
- proof of insurability;
- insurer endorsement;
- regulator-approved method;
- procurement recommendation;
- vendor ranking;
- score;
- standard;
- readiness certification;
- insurer-adopted method;
- public candidate unless explicitly authorized later;
- final/sealed unless explicitly authorized later;
- release-ready unless explicitly authorized later;
- public release unless explicitly authorized later.

## Required Phrase Discipline

- internal candidate;
- non-certifying research artifact;
- authored analytical model;
- non-scoring reasoning model;
- reviewability is not coverage;
- evidence is not insurance;
- auditability is not insurability;
- governance is not claim approval.

## R3T Boundary

No generation occurs in R3T. R3T defines controls only.
