## Candidate Source Decision

Future candidate generation should not use the R3P integrated draft directly for public-format generation. The recommended path is to create a controlled publication-candidate Markdown source in a future authorized generation-prep wave before HTML/PDF generation.

Rationale:

- It creates a stable source snapshot for artifact QA.
- It separates internal integrated drafting history from candidate source handling.
- It gives boundary, source, table, and status scans a fixed target.
- It reduces risk of mutating the R3P integrated draft.

- table IDs `T-02-01`, `T-04-01` through `T-27-01`;
- non-claim boundary status;
- WP3 public status until separately changed.
