# R3U Generation Planning QA Instructions

## Scope

R3U should QA R3T generation planning only.

R3U should not generate artifacts.

R3U should not create HTML, PDF, DOCX, manifest, or checksum files.

R3U should not modify public route.

## R3U Decision Options

R3U should decide whether to proceed to:

- generation planning repair;
- source strengthening;
- candidate source preparation planning;
- blocked.

## Public Status to Preserve

R3U must preserve WP3 public status:

- withdrawn / v1.0 rewrite in progress;
- public artifact none;
- public PDF none;
- public route noindex under-rewrite;
- no public DOCX authorized.

## Boundary

R3U must not claim public candidate, final, sealed, release-ready, coverage-ready, underwriting-ready, claim-ready, certified, score, standard, insurer-accepted, insurer-adopted method, or public release status.
