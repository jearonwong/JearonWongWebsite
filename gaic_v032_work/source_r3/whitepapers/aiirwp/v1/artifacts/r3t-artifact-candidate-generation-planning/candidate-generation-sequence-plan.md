# Candidate Generation Sequence Plan

## Purpose

Define the future sequence for generating an artifact candidate if separately authorized later.

R3T does not execute any phase. No artifact candidate is generated. No public route action is taken.

## Future Sequence

| Phase | Future action | R3T status |
|---:|---|---|
| 1 | Confirm source truth and status. | Planned only. |
| 2 | Create controlled publication-candidate Markdown source if authorized. | Planned only; not created in R3T. |
| 3 | Run boundary/non-claim pre-generation scan. | Planned only. |
| 4 | Run source/citation continuity scan. | Planned only. |
| 5 | Run table/layout readiness scan. | Planned only. |
| 6 | Generate internal HTML candidate if authorized. | Planned only; no HTML created in R3T. |
| 7 | Generate internal PDF candidate if authorized. | Planned only; no PDF created in R3T. |
| 8 | Generate manifest if authorized. | Planned only; no manifest created in R3T. |
| 9 | Generate checksum file if authorized. | Planned only; no checksum created in R3T. |
| 10 | Run artifact candidate QA. | Planned only. |
| 11 | Only later consider public route restoration after separate authorization. | Planned only; no route action in R3T. |

## Stop Conditions

- Stop before candidate source creation unless separately authorized.
- Stop before any HTML/PDF generation unless separately authorized.
- Stop before manifest/checksum generation unless separately authorized.
- Stop before public route or CTA work unless separately authorized.
- Stop before public candidate, final/sealed, release-ready, or public release status unless separately authorized.

## R3T Boundary

R3T produces this sequence plan only. It does not run commands, copy source files, create artifacts, create public staging, or modify public routes.
