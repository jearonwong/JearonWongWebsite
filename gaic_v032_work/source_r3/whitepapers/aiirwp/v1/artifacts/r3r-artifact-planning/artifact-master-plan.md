Public route restoration remains deferred. Public CTA restoration remains deferred. The current public route stays noindex under-rewrite until a later public-route wave explicitly changes it.

## Public Status Preservation

Until a separate public artifact wave is authorized, all artifact planning must preserve:

- withdrawn / v1.0 rewrite in progress;
- public artifact none;
- public PDF none;
- public route noindex under-rewrite;
- no public DOCX authorized.

## Non-Claim Preservation by Format

| Format | Required non-claim posture |
|---|---|
| Markdown | Internal planning/source status, not publication candidate unless later authorized. |
| HTML | Research artifact status must avoid public candidate/final/release-ready unless later authorized. |
| PDF | Must include status and boundary language; no final PDF readiness claim before QA. |
| Manifest | Must record status and source paths without implying release authorization. |
| Checksums | Integrity records only, not release certification. |

## R3R Boundary

R3R does not create artifacts, artifact paths under `public/research`, public staging, public CTA, route changes, manifest, checksum, HTML, PDF, DOCX, or release package.
