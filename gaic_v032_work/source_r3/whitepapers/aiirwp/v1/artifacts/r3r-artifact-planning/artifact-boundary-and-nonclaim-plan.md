# Artifact Boundary and Non-Claim Plan

## Purpose

Define artifact-level non-claim controls before any future artifact generation.

## Global Artifact Disclaimers

Future artifact formats must preserve that AIIRWP v1.0 is authored analytical research and not legal, insurance, underwriting, coverage, pricing, claim, certification, score, standard, or insurer-adopted method output.

## Format-Level Status Language

| Format area | Required planning language |
|---|---|
| Header/frontmatter | Internal planning or artifact candidate only if later authorized; not final, sealed, release-ready, or public release. |
| HTML page | Status must avoid public candidate/final/release-ready unless later authorized. |
| PDF | Status and boundary language must be visible; no final PDF readiness claim before QA. |
| Manifest/status | Integrity/status metadata only; not release certification. |

## Forbidden Positive Claims

Future artifact work must not positively claim:

- legal advice;
- insurance advice;
- underwriting guidance;
- coverage opinion;
- actuarial pricing guidance;
- premium recommendation;
- claim approval guidance;
- legal liability determination;
- certification;
- proof of insurability;
- insurer endorsement;
- regulator-approved method;
- procurement recommendation;
- vendor ranking;
- score;
- standard;
- readiness certification;
- insurer-adopted method;
- public candidate unless explicitly authorized later;
- final/sealed unless explicitly authorized later;
- release-ready unless explicitly authorized later;
- public release unless explicitly authorized later.

## Safer-Language Patterns

- internal planning;
- artifact candidate only if later authorized;
- non-certifying research artifact;
- authored analytical model;
- non-scoring reasoning model;
- reviewability is not coverage;
- evidence is not insurance;
- auditability is not insurability;
- governance is not claim approval.

## R3R Boundary

R3R defines controls only. It does not generate or implement artifact status language in any public file.
