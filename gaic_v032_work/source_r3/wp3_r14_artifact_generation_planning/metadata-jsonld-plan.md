# Metadata / JSON-LD Plan

## Scope

This plan applies to future public staging, not R15 internal candidate artifacts. R14 does not wire metadata or JSON-LD.

## Future Public Route

Future public staging should use:

`/research/agentic-ai-insurability-risk-transfer-white-paper-2026/`

The current editorial-review placeholder should be replaced only in a later staging wave after candidate artifacts pass QA.

## Metadata Pattern

Future public route metadata should align with GAIC/AIAAWP:

- Title.
- Description.
- Canonical.
- Robots.
- Open Graph.
- Twitter.
- Citation meta tags.
- Artifact identity.
- No DOCX exposure.

## JSON-LD Pattern

Future public JSON-LD should include:

- `WebPage`.
- `TechArticle`.
- `Report`.
- `BreadcrumbList`.
- `ItemList`.
- `DefinedTermSet`.
- `Person` reference.

AIO/AIRM should be described as analytical terms / Jearon Wong synthesis.

## Forbidden Metadata Claims

No certification, endorsement, insurer acceptance, coverage guarantee, underwriting-ready claim, legal proof, claims approval claim, external adoption claim, indexing claim, SEO/GEO outcome claim, or answer-engine recognition claim.

## R15 Rule

Internal candidate artifacts should not include public canonical or public JSON-LD.
