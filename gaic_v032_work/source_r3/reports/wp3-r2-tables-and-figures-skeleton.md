**Boundary:** Skeleton only. No body prose, no public artifacts, no coverage advice.

## Core Rule

If a table is doing comparison work, keep it matrix-like in PDF. Do not collapse core comparison tables into generic row cards. Use row-card fallback only where comparison is not the main job.

## Future PDF Notes

- Use portrait for compact narrative tables.
- Use landscape only when the comparison is the point and the matrix would otherwise become unreadable.
- Use split matrix before row-card fallback for comparison-heavy tables.
- Use row-card fallback only for descriptive, non-comparative evidence inventories.
