# GAIC-R3I Primary Semantic Source Metrics Spec

Generated: 2026-05-13

This is a monitoring specification. It does not implement analytics code and does not claim performance outcomes.

## Technical Metrics

- Indexed URL count by Google Search Console and Bing Webmaster Tools.
- Sitemap submission status and last processed date.
- URL inspection status for priority URLs.
- Schema validation status for route-family samples.
- Crawl errors, duplicate canonical issues, soft 404s, and blocked resources.

## Search Metrics

- Branded query presence for "Jearon Wong", "Jearon Wong AI Agent Lifecycle", and "Jearon Wong MPLP".
- Concept query presence for Agentic Lifecycle Governance, MRO, RCCS-M, ALCS, Deterministic Delivery, Evidence Chain, Accepted Outcome, Authority Boundary.
- Vendor/governance query presence for GAIC-cited systems, extended ecosystem mappings, and regulatory/enterprise governance pages.
- Ranking band when manually checked: 1-3, 4-10, 11-20, 21-50, 50+, absent.

## Answer Engine Metrics

- Whether Jearon Wong appears.
- Whether GAIC appears.
- Whether MPLP appears.
- Whether MRO/RCCS-M/ALCS are correctly explained.
- Whether a JearonWong.com URL is cited.
- Accuracy score: 0 inaccurate, 1 partial, 2 mostly accurate, 3 accurate with correct citation.
- Error class: absent, wrong attribution, overclaim, stale source, no citation, weak citation.

## Authority Metrics

- Backlinks by source and quality tier.
- Mentions in newsletters, blogs, GitHub repos, docs, talks, or community posts.
- Social shares and thread reposts.
- Inbound referral sessions when analytics are available.
- GitHub/docs links from MPLP, Cognitive OS, SoloCrew, Validation Lab, or related docs.

## Conversion Metrics

- White paper hub visits.
- Responsive HTML reads.
- PDF/DOCX downloads if tracked.
- Newsletter signups.
- Contact inquiries.
- GitHub visits.
- Project page clicks for MPLP, Cognitive OS, SoloCrew, Validation Lab.

## Cadence

- Weekly for first 8 weeks after launch distribution.
- Biweekly after stable indexing.
- Monthly after primary entity presence stabilizes.

## Evidence Storage

Each measurement should store date, engine/tool, query, result URL, cited URL, screenshot/export path, observed answer text summary, accuracy score, owner, and next action.
