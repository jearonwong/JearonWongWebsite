## Artifact-Stage Citation Recommendation

Use a hybrid citation note system:

- Keep numbered source markers in body only where needed.
- Render source families as chapter-level endnotes or clean publication footnotes.
- Preserve Appendix A as a method/source-note boundary if the artifact shell can keep it readable.
- Avoid reintroducing source inventory tables into the main body.

## Required R14 Action

R14 should define the citation rendering model before R15 candidate artifact generation. No R13B textual edit is required.
