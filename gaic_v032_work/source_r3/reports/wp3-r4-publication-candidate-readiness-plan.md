# WP3-R4 R5 Publication-Candidate Readiness Plan

## R5 Scope

R5 should prepare a publication-candidate package. R5 should not publish WP3.

## Recommended R5 Work

1. Assemble publication-candidate source package.
2. Normalize citations and source notes.
3. Finalize source register and citation map.
4. Finalize manifest plan.
5. Finalize metadata and JSON-LD plan.
6. Prepare HTML/PDF generation plan using GAIC/AIAAWP standards.
7. Keep DOCX internal only unless owner explicitly changes the public DOCX policy.
8. Prepare semantic mapping plan for any future public route.
9. Prepare public naming policy: use the public title, not internal `WP3` shorthand.
10. Perform final insurance/legal/source boundary sweep.
11. Prepare author review checklist.

## R5 Must Not Do Without Separate Approval

- Public release.
- Final seal.
- Insurer acceptance claim.
- Coverage-ready claim.
- Underwriting-ready claim.
- Public DOCX reintroduction.
