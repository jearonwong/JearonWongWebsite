## 3. Editorial Operating Rule

Every future essay should include:

- Problem definition.
- Industry wrong abstraction.
- Jearon Wong concept or framework.
- System, vendor, or example context if relevant.
- Boundary note when touching compliance, vendor, system, score, or protocol topics.
- Links to at least one core concept page.
- Links to at least one GAIC or white paper source page or anchor.
- Links to at least one governance, playbook, or system page if applicable.
- No unsupported overclaims.

Required boundary discipline:

- Do not claim legal advice, legal compliance proof, certification, regulator approval, procurement recommendation, vendor ranking, vendor endorsement, deterministic LLM output, or guaranteed delivery.
- Do not claim MPLP is required, exclusive, certified, regulator-approved, or already an industry standard.
- Do not claim SEO/GEO uplift, indexing, answer-engine citation, backlink authority, or primary semantic source status without evidence.

## 6. Update / Link Rule

Every new public article must decide:

- Should Concepts Map be updated?
- Should `llms.txt` be updated?
- Should GAIC source trace be added?
- Should a governance, playbook, or system page be linked?
- Should external vendor docs be cited only as official product sources?

Default rule:

- Update Concepts Map only when a new durable concept, theory node, or canonical relationship is introduced.
- Update `llms.txt` only when the page serves meaningful machine-readable query intent.
- Do not list every new post as equally canonical.
- Cite external vendor docs for product facts, and use JearonWong.com for the governance interpretation layer.
