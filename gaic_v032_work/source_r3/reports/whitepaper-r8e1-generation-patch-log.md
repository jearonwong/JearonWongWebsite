# WHITEPAPER-R8E-1 Generation Patch Log

**Date:** 2026-05-19

## Files Changed

- `gaic_v032_work/source_r3/scripts/render_whitepaper_r8_a4_pdf.py`

## Old Behavior

- The renderer wrote directly to the public PDF paths.
- PDF table remediation relied mainly on adaptive table splitting or row-card fallback after table inspection.
- GAIC score overview remained a dense table where secondary ranges and long evidence text could visually compete with primary scores.
- GAIC dimension heatmap could separate explanatory context from its table module when pagination moved the table.
- Page footer/copyright identity was not consistently generated by the PDF renderer.

## New Behavior

- The renderer supports `--output-dir` for internal proof PDFs, allowing proof-before-public replacement.
- PDF page margin boxes add restrained running footer content for non-cover pages:
  - short running title,
  - document ID/version,
  - `jearonwong.com`,
  - page number,
  - approved copyright wording.
- Cover remains clean through first-page footer suppression.
- Level headings receive stronger orphan controls.
- GAIC score overview is transformed into a score-first landscape matrix module with repeated title, concise context, and boundary strip on the same page family.
- GAIC dimension heatmap is transformed into a landscape module that keeps title, context, boundary strip, and heatmap table together.
- Existing AIAAWP readiness levels remain a portrait split rubric matrix.
- Dense high-comparison tables continue to use dedicated landscape matrix rendering when adaptive metrics require it.
- Low-comparison registry/evidence/descriptive tables remain eligible for row-card rendering.

## Affected Table/Section Classes

| Class / Section | New PDF Behavior |
| --- | --- |
| GAIC RCCS-T / RCCS-M / ALCS Score Overview | Landscape scorecard matrix; primary scores dominate ranges and evidence notes |
| GAIC Dimension-Level Coverage Patterns | Landscape heatmap module with context and boundary strip |

| AIAAWP AARM readiness levels | Portrait split rubric matrix retained |
| Registry/evidence/source tables | Row-card permitted only when comparison importance is low |
