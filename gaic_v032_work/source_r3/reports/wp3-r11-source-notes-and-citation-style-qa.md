# WP3-R11 Source Notes and Citation Style QA

## Assessment

The numbered source-note system `[1]-[9]` is acceptable as an internal rewrite convention, but it is not yet the cleanest possible publication citation style.

## Findings

| Check | Result | Note |
| --- | --- | --- |
| Source references are too dense in the body | PARTIAL | The body uses note markers often, especially in Chapters 0-6 and 10. |
| Source notes feel like support rather than residue | PASS | They are cleaner than the old raw source tags and do not read like a source pack dump. |
| Source notes are too compressed | PARTIAL | Several notes cover broad source families, especially market and governance context. |
| Claims are under-supported because one note covers too much | PARTIAL | Chapter 5 and Chapter 7 would benefit from more granular chapter-level notes. |
| Technical framework claims are kept separate from insurance conclusions | PASS | AIO/AIRM are explicitly labeled as authored synthesis. |
| AIO/AIRM are clearly identified in prose | PASS | The body states that AIO and AIRM are authored vocabulary, not standards. |

## Recommendation

**Publication citation style recommendation:** hybrid citation notes.

Use:

- body-level numbered notes for the R12 rewrite,
- chapter-level source notes or footnotes in the next publication-facing step,
- appendix notes for the deeper source families.

## R12 / R13 Action

- Keep numbered notes for the rewrite stage.
- Split the broad Chapter 5 and Chapter 7 note families into more granular chapter-level source notes.
- Move toward footnotes or endnotes before any artifact-generation step if the body expands further.
