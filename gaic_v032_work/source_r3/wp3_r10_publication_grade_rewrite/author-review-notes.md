# WP3-R10 Author Review Notes

## What to Read First

1. Chapter 0 to confirm the paper opens with the reader problem.
2. Chapters 1-3 to confirm the subject / object / responsibility ladder stays clear.
3. Chapter 5 to make sure the market edge is described carefully and not overstated.
4. Chapter 8 to check that AIO feels like an answer, not a dump.
5. Chapter 9 to check that AIRM reads as readiness vocabulary, not certification.

## What to Watch For

- Any sentence that sounds like a coverage opinion.
- Any paragraph that slips back into source-pack voice.
- Any line that treats logs as claim evidence by themselves.
- Any line that makes HITL sound like responsibility mapping.
- Any line that makes tool permission sound like coverage authority.
- Any line that makes readiness sound like acceptance or certification.

## Revision Bias

If a paragraph feels too procedural, pull it back toward the reader problem.
If a table feels too complete, trim it until it helps the argument.
If a concept appears too early, move it later.

## Review Outcome

This note file is for the next editorial pass. It does not claim final author approval.
